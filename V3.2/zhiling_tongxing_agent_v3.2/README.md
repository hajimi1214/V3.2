# 智领铜行--人工智能机械臂多Agent智能决策平台 V3.2

## 平台定位

本平台围绕铜箔卷抓放、机械臂与 AGV 协同、PLC 联锁和上位机指令下发场景建设，将算法模型、工业状态帧、设备联锁、动作权限矩阵和安全约束纳入同一条多 Agent 决策链路。

## V3.2 更新内容

### 1. 前端工程结构整理
- 将原本集中的前端脚本拆分为平台基础、设备运行、决策拓扑、模块中心、决策执行、运行元数据、Agent 审查、工作流画布、仲裁策略、模型导入、导航外壳、工业状态媒体、执行拓扑、指令下发和设备持久化等子系统。
- 文件命名统一改为工业平台语义命名，不再使用历史迭代号作为模块文件名。
- `static/app.js` 仅保留模块加载清单，便于后续维护和定位问题。

### 2. 多 Agent 决策与安全仲裁
- 保留视觉质量 Agent、三维定位 Agent、放置规划 Agent、硬件联锁 Agent、安全策略 Agent、执行约束 Agent 和融合仲裁 Agent。
- 工作流配置通过 `static/workflow_config.js` 写入本地配置，Agent 总线完成后才进入控制任务生成和指令下发阶段。
- 指令下发前增加 Agent 仲裁完成校验，避免异常操作绕过视觉、定位、路径、安全联锁等 Agent 审查。

### 3. 模型适配与运行配置
- `static/model_adapter.js` 保留模型适配入口，可登记图像修复模型、YOLO 识别模型和双目测距模型。
- 模型登记结果写入 `agent_model_registry` 和 `agent_model_input`，供视觉质量 Agent 和三维定位 Agent 调用。

### 4. 测试交付文档
- `docs/接口文档.md`、`docs/测试文档.md`、`docs/测试用例.csv` 保持每类文档一份。
- 文档刷新开关可在后端入口中按需启用，用于更新生成时间、启动批次和 API 测试密钥。
- 文档面向测试工程师，用于接口测试、异常场景验证、性能探针和 Trace 复核。


```text

```

